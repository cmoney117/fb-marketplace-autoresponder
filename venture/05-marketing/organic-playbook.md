# Organic Traffic Playbook (no ad spend)

Built from `02-research/04-marketing-and-traffic.md`. Priority order is fixed by that research: **marketplace SEO does the heavy lifting; Pinterest compounds in the background; everything else is optional.** All of it runs on official APIs/schedulers — nothing here risks an account.

## Channel 1 — Etsy SEO (the main engine, fully agent-run)

**The play:** Etsy already has buyers searching with wallets out. We "generate traffic" by publishing well-optimized listings at volume and letting the recency boost + listing-quality flywheel work.

- **Volume plan:** launch with 30–40 listings; daily ops run adds 5–10/week; target 150+ live listings by month 4 (community data: meaningful search traffic starts ~30–50 listings, compounds at 100–150+).
- **Every listing follows `07-automation/pipelines/listing-copy-generator.md`:** front-loaded keyword title, all 13 multi-word tags, every attribute filled, first-two-lines keyword-relevant description.
- **Narrow beats broad:** target specific buyer searches ("ICU nurse graduation gift shirt") over generic ("funny shirt") — 2025-2026 algorithm favors converting well in narrow queries.
- **Shop-level hygiene (one-time):** complete About section, free-US-shipping pricing built into item price, fast message responses (the CS agent handles this).
- **Refresh cycle:** weekly run refreshes stale listings (new photos/tags) per the kill/scale rules.
- **Disclosures always on:** production partner (POD), AI-generated imagery where used (2025+ requirement — suspension trigger if skipped).

**Expectations (honest):** first sale typically weeks 2–12; the algorithm needs 30–60 days to learn new listings. Silence in month 1 is normal, not failure.

## Channel 2 — Pinterest (compounding background channel, fully agent-run)

**Why:** 619M users, 55% use it to shop, evergreen pins keep driving clicks for months — and scheduled/programmatic pinning via official API partners is explicitly allowed.

- **Volume:** 10–15 pins/day via Buffer (free, 3 channels) to start; upgrade to Tailwind Pro ($17.99/mo) when pin volume justifies. Never burst >50/hour (spam filter).
- **Pipeline:** every new product automatically gets 2–3 pin variants (1000×1500, text-overlay value prop) linking to its listing. Boards per niche, not per product.
- **Expectations:** months 1–3 near zero, meaningful clicks months 4–6, compounding after. This is a patience channel — free to run, so it runs from day one.

## Channel 3 — Email (activates with own store; light version before)

- Before own store: collect emails compliantly via a freebie landing page (free printable/sample design) linked from packaging inserts and social bios — never by emailing Etsy buyers (policy violation).
- Own-store launch day one: MailerLite free tier → abandoned-cart flow (~$3.65/recipient benchmark), welcome series (~$2.65/recipient), post-purchase flow. Flows are ~41% of e-com email revenue from ~5% of sends — build once, runs forever.

## Channel 4 — Short-form video (lottery ticket, agent-generated, optional)

1 faceless product video/day (AI-generated slideshow/b-roll + text + voiceover), published via official APIs (TikTok Content Posting API, Instagram Graph API) or Buffer. Judge at 90 days: any video >50k views → double down on that format; otherwise keep it at zero-marginal-effort volume. Never buy engagement.

## Channel 5 — Reddit/communities (human/VA only, later)

Only after a VA is hired, only in promo-permitted threads, always disclosed, 90/10 participation rule. Agents use Reddit read-only (niche research). No exceptions — this is the fastest way to burn a brand and it's in the never-automate list.

## What we deliberately skip (and why)

- **Blog/programmatic SEO:** 6–12+ months to traffic on a zero-authority domain; marketplaces beat it on every timeline. Revisit only post-own-store.
- **Any engagement automation:** mass DMs, auto-comments, follower buying — documented ban waves + FTC fake-review penalties up to $51,744/violation. The whole business runs on accounts in good standing; nothing is allowed to threaten that.
