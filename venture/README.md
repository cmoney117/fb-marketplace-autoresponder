# Venture HQ — Automated E-Commerce Income Project

This folder is the complete headquarters for the automated online-selling venture. It is organized so **you** (the owner) read the numbered folders top-down, and **any AI agent** can rebuild full context from `99-ai-handoff/` alone.

## Start here

Read **`01-START-HERE.md`** first. It contains the executive summary, what was decided and why, and the single batched list of tasks only you can do (account signups, identity verification, bank linking).

## Ground rules this project runs on

1. **Validate before spending.** No inventory purchases, no ad spend, until organic marketplace sales prove demand.
2. **Real numbers only.** Every projection in these docs traces to a sourced number in `02-research/`. No guru math.
3. **Compliant automation only.** Official APIs, scheduling tools, and human VAs. No engagement bots, no DM spam, no fake reviews — those get accounts (and payment processors) banned, which kills the whole machine.
4. **Protect the payment rails.** Dispute rate is the metric that can end this business overnight. See `04-operations/compliance-and-risk.md`.
5. **Low-touch, not zero-touch.** Target owner time: 1–3 hours/week after setup. Anything requiring identity, banking, or account creation is batched into `01-START-HERE.md`.
